# [구현 계획] 모바일 텍스트 뷰어 (HappyText Reader)

형님께서 요청하신 안드로이드 모바일 최적화 텍스트 뷰어의 전체 설계 및 단계별 구현 계획서입니다.
본 앱은 야간 독서 시 눈의 피로를 최소화하고, 문맥에 맞지 않는 어색한 줄바꿈을 완벽히 교정하며, 대용량 소설 파일도 렉 없이 매끄럽게 읽을 수 있도록 설계되었습니다.

---

## 1. 핵심 요구사항 분석 및 해결 방안

| 요구사항 | 상세 내용 | 해결 방안 |
| :--- | :--- | :--- |
| **1. 첫 화면: 도서관 (Library)** | - 작품 목록 노출<br>- 작품 클릭 시 내부 txt 권별 목록 표시<br>- 작품 추가/삭제/이름 변경 | - 모바일 서재 UI (도서관 뷰 ↔ 작품 상세 뷰 2단 네비게이션)<br>- `묵향`(1~28권) 기본 자동 임포트 시드 제공<br>- 사용자 로컬 파일/폴더 추가 기능 (`<input type="file" webkitdirectory>` 및 개별 txt 다중 선택) |
| **2. 프로세스 메모리 상태 유지** | - 앱 실행 시 보던 페이지/위치 그대로 즉시 복원 | - `ActiveSessionStore` (IndexedDB + LocalStorage 이중화)<br>- 마지막 읽은 [작품 ID, 권 번호, 스크롤 위치 / 페이지 인덱스, 폰트 설정] 실시간 동기화<br>- 앱 재진입 시 도서관 거치지 않고 바로 '이어보기' 즉각 렌더링 |
| **3. 야간 눈부심 방지 차분한 테마** | - 밤에도 눈부시지 않고 차분한 색상 배치<br>- 화려함 지양, 극상의 편안함 | - 무광(Matte) 텍스처 중심의 4가지 저자극 테마 프리셋 제공:<br>  1) **심야 올레드(AMOLED)**: 완전 블랙(#000000) + 웜 라이트그레이(#b5b5b5)<br>  2) **달빛 차콜(Default)**: 부드러운 차콜(#161719) + 크림화이트(#d4d4d8)<br>  3) **편안한 세피아**: 눈이 가장 편안한 톤다운 황토빛(#26221d / #e2d9cc)<br>  4) **소프트 린넨**: 주간용 반사광 억제 오프화이트(#eae7dc / #2b2b2b) |
| **4. 스마트 텍스트 개행 (가독성 극대화)** | - 한 단어만 나오고 개행되는 현상 방지<br>- 작가의 의도적 짧은 줄은 유지 | - **스마트 문단 정돈 엔진(SmartParagraphReflower)**:<br>  1) PC통신/80열 강제 줄바꿈(Hard Wrap) 감지: 이전 줄이 문장 마침표/따옴표가 아니고 다음 줄이 이어지는 문장이면 자연스럽게 공백 병합(Unwrap)<br>  2) 작가 의도 보존: 대화문(`"..."`, `'...'`), 장/절 구분(`---`, `[..]`), 시적 짧은 행간, 빈 줄은 보존<br>  3) CSS: `word-break: keep-all; text-wrap: pretty; line-height: 1.8;`로 어절 중간 잘림 방지 |
| **5. 대용량 파일 & 인코딩 처리** | - 묵향 등 500KB~수MB txt 파일<br>- CP949(EUC-KR) 인코딩 호환 | - Web Worker 백그라운드 파싱으로 메인 UI 60fps 무지연 보장<br>- CP949 / UTF-8 자동 판별 디코더 탑재 |

## 2. 형님을 위한 추가 아이디어 제안 (Value-Add Features)

1. **독서 방식 2-in-1 지원 (스크롤 ↔ 페이징)**
   - 위아래로 자연스럽게 내리는 **[웹툰식 세로 스크롤 모드]**
   - 손가락으로 툭툭 치거나 넘기는 **[전자책식 좌우 페이징 모드]**
2. **소제목/목차 자동 추출 (Chapter Drawer)**
   - 텍스트 파일 내 "제 N 권", "제 N 장", "--- 서문 ---" 등의 패턴을 정규식으로 감지하여 좌측 드로어에서 챕터별로 원터치 점프.
3. **미니멀 플로팅 리더 메뉴**
   - 화면 중앙을 탭했을 때만 부드럽게 나타나며 글자 크기(A- / A+), 줄간격, 여백, 테마를 1초 만에 변경 가능.
4. **한눈에 보는 독서 진행률 인디케이터**
   - 화면 상단/하단에 얇은 미니멀 진행선과 함께 "묵향 01권 · 42.5%" 깔끔 표시.

## 3. 시스템 아키텍처 및 모듈 분할 (500줄 제한 및 성능 준수)

파일이 비대해지지 않도록 단일 책임 원칙(SRP)에 따라 200~300줄 내외의 독립 모듈로 구성합니다.

```
happytext/
├── index.html                  # 모바일 뷰포트 & PWA 설정
├── package.json
├── vite.config.ts
├── src/
│   ├── main.tsx                # 엔트리 포인트
│   ├── App.tsx                 # 최상위 라우터 및 상태 공급
│   ├── types/
│   │   └── book.ts             # 작품, 권, 독서상태 타입 정의
│   ├── styles/
│   │   ├── variables.css       # 차분한 테마 색상 토큰
│   │   └── index.css           # 글로벌 리셋 및 가독성 타이포그래피
│   ├── workers/
│   │   └── textParser.worker.ts # [성능] 대용량 텍스트 파싱 & 스마트 개행 워커
│   ├── services/
│   │   ├── db.ts               # IndexedDB 로컬 저장소 (작품, 권, 텍스트)
│   │   ├── encoding.ts         # CP949 / UTF-8 자동 감지 디코더
│   │   └── sessionStore.ts     # 프로세스 유지 & 이어보기 상태 관리
│   ├── utils/
│   │   └── textReflow.ts       # 스마트 단락 재조합 & 개행 정돈 순수함수
│   ├── hooks/
│   │   ├── useLibrary.ts       # 도서관 작품 관리 훅 (추가/수정/삭제)
│   │   └── useReader.ts        # 뷰어 스크롤/페이지/진행률 훅
│   └── components/
│       ├── library/
│       │   ├── LibraryView.tsx     # 서재 메인 (작품 목록)
│       │   ├── BookCard.tsx        # 개별 작품 카드
│       │   ├── VolumeListModal.tsx # 권별 목록 팝업/화면
│       │   └── BookEditModal.tsx   # 작품 추가/이름수정 모달
│       ├── reader/
│       │   ├── ReaderView.tsx      # 리더 메인 컨테이너
│       │   ├── ReaderContent.tsx   # 텍스트 가상화 렌더러
│       │   ├── ReaderToolbar.tsx   # 미니멀 상/하단 툴바
│       │   ├── ChapterDrawer.tsx   # 자동 감지 목차 드로어
│       │   └── SettingsModal.tsx   # 글자크기/줄간격/테마 설정
│       └── common/
│           ├── ConfirmDialog.tsx   # 삭제/확인 팝업
│           └── ProgressBar.tsx     # 상단 진행률 바
```

## 4. 단계별 구현 일정

- **1단계: 프로젝트 환경 구축 및 디자인 시스템 세팅**
  - Vite + React + TypeScript 환경 셋업
  - 차분한 다크/세피아/올레드 테마 변수 및 typography 정의 (`word-break: keep-all`)
- **2단계: 텍스트 파싱 & 스마트 개행 엔진 및 Web Worker 구축**
  - CP949 / UTF-8 자동 디코딩
  - 스마트 문단 unwrap 알고리즘 단위 검증 (묵향 01권 대상)
  - 챕터 추출기 구현
- **3단계: IndexedDB 및 세션 관리자 구현**
  - 작품/권 스키마 정의
  - 묵향 01~28권 기본 데이터 번들링 및 로컬 저장
  - 프로세스 복원(이어보기) 스토리지 구현
- **4단계: 도서관(Library) UI 구현**
  - 작품 카드 목록 (진행도, 권수 표시)
  - 권별 파일 목록 보기 및 즉시 열람
  - 작품 추가(로컬 txt 파일/폴더 선택), 이름 변경, 삭제 기능
- **5단계: 모바일 독서 뷰어(Reader) UI & 인터랙션 구현**
  - 세로 스크롤 및 좌우 페이징 뷰
  - 눈부심 없는 야간 테마 전환기
  - 제스처 기반 툴바 토글 & 목차 이동
- **6단계: 성능 최적화, 묵향 01권 실전 테스트 및 검증**
  - 500KB 대용량 텍스트 스크롤 60fps 점검
  - 어색한 개행 발생 여부 꼼꼼 검수
  - 브라우저 재진입 시 이어보기 위치 100% 일치 확인
