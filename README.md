# HappyText 📖✨
> 안드로이드 모바일 환경에 최적화된 야간 저자극 오프라인 텍스트 뷰어 (PWA / WebAPK)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Version](https://img.shields.io/badge/version-v2.1.0-brightgreen.svg)]()

HappyText는 눈의 피로를 최소화하고, 수백 권의 한국 웹소설/텍스트 파일을 모바일에서 가장 편안하게 감상할 수 있도록 개발된 초경량 고성능 웹 텍스트 뷰어입니다.

---

## 🌟 주요 특징 (Key Features)

### 1. 순수 DOM 페이지 분할 렌더링 엔진 (Pure Page DOM Paginator)
- 기존 가로 스크롤/좌표 이동(`transform`) 방식에서 발생하던 누적 픽셀 오차 및 글자 밀림 현상을 원천 박멸.
- 현재 페이지에 해당하는 텍스트만 DOM에 정확히 마운트하여 **오차 0.00px** 및 **0초 즉각 전환** 구현.
- 화면 스크롤이나 스와이프 제스처로 인한 흔들림 없이 가볍게 탭하는 것만으로 페이지 넘김.

### 2. 야간 저자극 4대 감성 테마
- **OLED Black**: 완벽한 암실용 트루 블랙 (`#000000`)
- **Charcoal**: 모던하고 차분한 다크 그레이
- **Sepia**: 눈이 편안한 따뜻한 책 종이 질감
- **Linen**: 은은하고 부드러운 내추럴 크림 톤

### 3. 고전 CP949(EUC-KR) 및 UTF-8 자동 판별 엔진
- 90년대 PC통신 소설부터 최신 텍스트 파일까지 인코딩 깨짐 없이 100% 자동 디코딩.
- 80열 강제 개행(Hard wrap) 자동 언래핑(Unwrap) 및 한글 조사 분절 복원 (`word-break: keep-all;`).

### 4. PWA WebAPK & 완전 오프라인 지원
- 홈 화면 추가(WebAPK) 지원으로 네이티브 앱처럼 동작.
- 서비스 워커(Service Worker) 및 IndexedDB 영구 저장소 탑재로 비행기 모드나 오프라인에서도 모든 책을 즉시 열람 가능.

### 5. 프로세스 메모리 상태 100% 보존
- 앱을 종료하거나 새로고침해도 마지막으로 읽던 작품, 권, 페이지를 즉시 복원하는 활성 세션 스토어.

## 🚀 빠른 시작 (Getting Started)

### 설치 및 실행
```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev
```

### 프로덕션 빌드
```bash
npm run build
```

## 📱 조작 가이드
- **상단 30% 영역 탭**: 목차 및 환경설정 툴바 표시 / 숨김
- **하단 70% 중 우측 탭**: 다음 페이지 즉각 넘김
- **하단 70% 중 좌측 탭**: 이전 페이지 즉각 넘김
- **하단 70% 중 중앙 탭**: 툴바 표시 / 숨김
